# 🩺 PooDev: Sistema de Prontuário Médico Inteligente

Este projeto foi desenvolvido como requisito para a disciplina de **Programação Orientada a Objetos e Desenvolvimento de Sistemas (PooDev)**. 

O objetivo do sistema é otimizar o fluxo de atendimento médico em clínicas, conectando o banco de dados interno diretamente à tela do profissional de saúde. O sistema processa e exibe os dados do paciente de forma inteligente, eliminando a necessidade de buscas manuais extensas.

## 🚀 Principais Funcionalidades

* **Painel do Atendimento Atual:** Exibição imediata do motivo da consulta e sintomas atuais do paciente.
* **Histórico Centralizado:** Acesso rápido ao registro de todas as visitas, exames e procedimentos anteriores realizados na clínica.
* **Destaque de Informações Críticas:** Sistema de alertas visuais para dados importantes (alergias, condições crônicas, medicações de uso contínuo), poupando o tempo do médico.
* **API RESTful:** Desenvolvida em Java.

## 🛠️ Tecnologias Utilizadas
* Java
* PostgreSQL
